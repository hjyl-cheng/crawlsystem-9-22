# M1 控制台页面设计与验收对照

日期：2026-09-23。状态：已按 G0/G1 `m1.v1` 契约实现前端并完成实际 API 验证；当前交付结果、证据和接口限制见[控制台报告](../../../docs/m1/reports/console.md)。

依据：[控制台任务单](../../../docs/m1/agent-console.md)、[共同规则](../../../docs/m1/README.md)。本文件保留实施前的设计与验收目标，不代表每项目标均已验证。API 路径、字段名和业务枚举统一使用主 Agent 发布的公共契约；实际覆盖范围以交付报告为准。

## 1. 页面结构

| 页面 | 主要内容 | 操作与关联 |
| --- | --- | --- |
| 频道列表 | 频道身份、名称、测试标识、数据可用性、来源与更新时间 | 使用 G0 支持的过滤和分页；进入频道详情 |
| 频道详情 | 已持久化的基础资料、视频、评论、Agent 结果及各自来源、观察时间、输入版本与可用性 | 进入关联 Plan；视频和评论按契约有界查询 |
| Plan 列表 | Plan 身份、频道、样本标识、本轮目标、权威状态、等待/失败原因及状态时间 | 创建样本 Plan；按 G0 支持的条件筛选；进入详情 |
| Plan 详情 | 本轮必需领域、领域结果、阶段、依赖等待、执行实例、最近回执、关联错误、当前版本与交付状态 | 有权限时取消本轮；跳转频道、Worker、节点及回执 |
| Worker / 节点 | 登记的节点关系、Worker 身份、版本、接单状态、最近心跳、服务端判定的连接状态、代理接入情况 | 查看相关错误及 Plan；不提供尚未实现的运维操作 |
| 错误列表与详情 | 类别、阶段、首次/最近时间、错误原因及后端提供的关联身份 | 进入关联 Plan、Worker、节点和回执；缺失关联明确显示未提供 |

列表的过滤和翻页状态可返回恢复。详情身份来自导航参数；不存在、无权查看和请求失败分别反馈，不用空详情替代。

## 2. 数据展示规则

- 频道当前可用数据、本轮 Plan 结果、Agent 执行状态、对外交付状态分别展示，并保留各自的版本与时间。已有历史数据不能冒充本轮产出。
- Plan 的完整成功、部分完成、取消与领域必需性均以服务端契约为准。前端不根据非空数组、心跳、HTTP 成功或单个回执推导完成。
- 字段值为未知时不填零；合法空结果、未采集、不可获得、评论关闭按契约区分。零值必须来自实际返回值。
- Agent 未执行时呈现“未执行”；存在固定样本结果时标明样本来源。不能显示成真实模型执行成功。
- 交付未实施时呈现“未启用”。固定样本未使用代理时明确说明；没有代理查询数据时不显示虚构健康度或额度。
- 每个列表只说明本页记录。总量、指标、统计口径和统计时间均由后端提供；未返回总数时只展示前后翻页能力。
- Worker 最近心跳时间与失联判定分别显示。服务端状态不可查询时显示状态未知及最近成功查询时间，不在浏览器中自创失联阈值。
- 错误和回执的关联仅来自后端身份，不通过名称、日志文本或时间邻近推测关联。

## 3. G0 输入需求对照（实施前清单）

以下保留实施前的接口需求清单，不是另行发布的协议。G0 已发布并接入；当前没有错误聚合、直接错误/回执关联、正式账户管理或独立节点详情接口，对应限制已记录在交付报告。响应示例描述页面应能还原的场景，具体类型、路径、错误码与枚举由公共契约确定。

| 能力 | 必需事实或约束 | 响应语义示例 |
| --- | --- | --- |
| 工程基线 | 完整提交 SHA、Node/包管理器版本、公共契约导入入口、检查命令 | 同步固定提交后，控制台可以直接导入实体类型、输入校验、状态和错误定义 |
| 身份与授权 | 会话获取/续期/退出方式、只读与操作权限、对象授权、浏览器跨域/CSRF 约定 | 当前身份可读指定对象但不可创建或取消；服务端拒绝包含可展示原因和请求关联标识 |
| 样本创建 | 合法样本目录或固定样本输入、目标与必需领域、幂等身份作用域和有效期、创建响应或恢复查询 | 相同身份与输入返回同一 Plan；响应丢失后能核对原计划；身份相同但输入不同明确冲突 |
| 列表查询 | 支持的过滤项、默认顺序、页大小上限、分页机制、样本/正式标识 | 第一页返回有界记录及下一页依据；没有总量时不宣称系统共有多少条 |
| 频道详情 | 基础资料、视频、评论、Agent 的值/可用性/来源/时间/版本；大集合分页方式 | 基础资料已可用，评论合法为空，Agent 尚未执行；三个区域分别如实展示 |
| Plan 详情 | 业务身份、本轮目标、必需领域、领域结果、阶段、等待/失败原因、版本、状态时间、交付状态 | 基础资料已入库，评论仍在等待，Plan 尚未完整成功，交付未启用 |
| 执行与回执 | 执行实例身份、执行代次及阶段；有界回执列表、回执详情与领域/Plan 关联 | 最近一笔回执已经持久接收某领域数据，但其他必需领域仍缺失 |
| 取消本轮 | 对象权限、期望版本、幂等规则、请求已接受与持久取消的区别、版本冲突响应 | 页面版本过期时拒绝取消并提示刷新；请求被接受不等于已持久取消 |
| Worker / 节点 | 登记关系、身份、版本、接单状态、心跳时间、服务端判定状态与判定时间 | Worker 已停止心跳，服务端返回失联；页面同时保留其最后心跳时间 |
| 代理状态 | 已接入与未使用/未接入的准确语义；实际状态及来源时间 | 固定样本没有使用代理，页面明确显示该事实 |
| 错误查询 | 类别、阶段、首次/最近时间、有界分页、Plan/Worker/节点/回执关联 | 错误详情含 Plan 与回执身份，用户可逐一打开对应详情 |
| 错误与节流 | 未认证、无权限、不存在、版本冲突、限流、不可用、响应不兼容的公共错误样例 | 服务不可用时展示失败及重试入口；限流遵守服务端重试提示且有客户端预算 |
| 真实联调 | 隔离环境、API 地址、浏览器认证配置、端口、测试身份、安全注入方式、启动/停止命令 | 浏览器使用只读/操作身份访问实际 API，创建计划并核对持久回执；凭据不进截图或仓库 |

## 4. 请求、刷新与操作流程

### 查询与恢复

1. 页面首次进入显示加载状态；查询成功后再判断有记录或合法空结果。
2. 每个查询有超时、取消信号与响应校验。导航、筛选变化、退出或身份切换会终止旧请求；旧响应不得覆盖新对象或新身份的状态。
3. 详情轮询同一时刻只有一个请求；间隔、最大退避、连续失败次数与单次自动刷新时长均有上限。最终数值按 G0 服务预算落地并写入运行说明。
4. 页面隐藏时暂停轮询，恢复可见时按预算更新；卸载清理定时器。到达预算后显示“自动更新已暂停”，由用户主动恢复。
5. 后续查询因网络或服务失败时，可保留上次成功数据，但必须显示“数据可能已过期”、最后成功时间和失败原因。未认证、权限拒绝或身份变化时清除原身份下的数据与操作入口。
6. 接口异常或响应不兼容不回退到演示数据。演示和故障样本只能用于明确标识的测试环境。

### 创建样本 Plan

1. 根据真实权限显示创建入口；展示契约允许的样本、目标与必需领域。
2. 确认输入后为本次逻辑创建建立稳定幂等身份，提交期间锁定输入并阻止重复提交。
3. 成功后进入服务端返回的 Plan；展示持久状态并开始有界查询。
4. 超时、断网或结果不明时保留原输入和幂等身份，通过契约允许的重放/查询核对结果。不自动创建另一轮计划；结果明确后才能开始新的逻辑创建。
5. 按公共错误区分输入错误、幂等冲突、权限拒绝和服务不可用。是否允许重试由契约决定。

### 取消本轮

1. 操作入口依据权限与服务端允许操作判断。确认界面指明当前 Plan 和取消影响；取消确认不是取消成功。
2. 提交包含当前查看版本和契约要求的操作身份，提交期间禁用重复操作。
3. 请求接受后继续核对持久状态；只有后端返回对应取消事实才展示已取消。
4. 版本冲突保留当前 Plan 身份与已知版本，明确提示状态已变化、需要刷新；不自动用新版本再次取消。
5. 刷新后重新呈现权威状态，由用户重新决定是否取消。权限拒绝展示后端允许公开的原因，更新操作可用性。

## 5. 验收场景

页面测试使用 G0 的公共样本与契约。表中“真实接口”必须在真实 Control API 和持久存储上验证，浏览器拦截或测试替身结果单独记录。

| 场景 | 必须观察的页面行为 | 验证层级 |
| --- | --- | --- |
| 首次加载与空列表 | 加载与空结果可区分；空列表不显示失败 | 页面测试 |
| 分页与过滤 | 请求受页大小限制；切换过滤后无旧页残留；未返回总数时不展示总量 | 页面测试 + 真实接口 |
| 创建固定样本 | 显示样本身份，详情身份与创建响应一致，能看到真实执行记录 | 真实接口 E2E |
| 连点创建 | 同一逻辑操作保持同一幂等身份，不产生第二个业务 Plan | 页面测试 + 真实接口 |
| 创建响应丢失 | 使用原身份核对或重放，最终定位同一 Plan | 受控故障 + 真实接口 |
| 等待必需领域 | 显示具体等待原因和必需领域；已有数据可查看，Plan 不误报完整成功 | 页面测试 + 真实接口 |
| 部分数据可用 | 当前可用数据与本轮领域结果的版本/时间可区分 | 页面测试 + 真实接口 |
| 固定样本完成 | 页面完成范围、回执、领域状态与持久事实一致；不宣称真实采集/模型执行通过 | 真实接口 E2E |
| 评论合法为空或关闭 | 与未采集、请求失败、总量未知正确区分 | 公共样本页面测试 |
| Agent / 代理 / 交付未实施 | 对应区域明确显示未执行、未使用/未接入、未启用 | 页面测试 + 真实接口 |
| 执行失败关联 | 从错误进入对应 Plan 和最近回执，关联身份与服务端一致 | 真实接口 E2E |
| Worker 停止心跳 | 服务端判定失联后显示失联及最后心跳，不由浏览器自行判定 | 真实接口 E2E |
| 只读身份 | 无可执行写入口；直接写请求也被后端拒绝 | 页面测试 + 真实接口 |
| 操作中权限被收回 | 明确显示权限拒绝，不显示操作成功；受限数据不继续展示 | 页面测试 + 真实接口 |
| 页面版本过期 | 取消被拒绝，提示刷新且不自动重提 | 真实接口 E2E |
| 正常取消与迟到结果 | 以持久取消事实更新；迟到结果不能使页面误报成功 | 真实接口 E2E |
| 网络失败或服务不可用 | 显示失败/过期、最后成功时间与恢复入口，不切换假数据 | 页面测试 |
| 轮询预算与离开页面 | 不重叠、不无限重试；离开后中止请求，旧响应不覆盖当前页面 | 页面测试 |
| 不存在或无权访问的详情 | 明确反馈，无空壳成功页面，无原身份数据残留 | 页面测试 + 真实接口 |
| 响应不符合公共契约 | 显示兼容性错误及可公开的关联信息，不渲染推测状态 | 页面测试 |

真实 E2E 报告记录代码 SHA、契约版本、隔离环境、命令、浏览器及版本、场景结果、测试 Plan/回执身份和必要截图。凭据由环境注入，证据不记录授权头、Cookie 或 Secret。
